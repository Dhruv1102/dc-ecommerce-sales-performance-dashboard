# 📊 DC E-Commerce Sales Performance Dashboard

An interactive **Power BI dashboard** built to analyze e-commerce sales performance through dynamic visualizations and business insights. The dashboard provides a clear overview of sales, profit, customer behavior, payment methods, and product performance using interactive filters.

## 🎯 Project Overview

This dashboard transforms raw e-commerce data into meaningful business insights, helping users monitor KPIs and identify sales trends through an interactive and user-friendly interface.

---

## ✨ Features

- 💰 Total Sales, Units Sold, Total Profit & Average Order Value (AOV)
- 📈 Monthly Profit Trend Analysis
- 🏆 Top 5 States by Sales
- 👥 Top 5 Customers
- 🛍️ Sales Distribution by Category
- 💳 Orders by Payment Mode
- 📊 Top 5 Profitable Sub-Categories
- 🎛️ Interactive Filters (Year, Quarter, Category & State)
- 🔄 Reset Filter Button

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Power Query
- Data Modeling

---

## 📌 Key Insights

- Uttar Pradesh generated the highest sales.
- Profit remained consistent throughout the year, with August recording the highest profit.
- UPI and Credit Card were the most preferred payment methods.
- Dolls emerged as the most profitable sub-category.
- Grocery and Toys contributed significantly to category sales.
